- 준비
    1. git 다운로드
    2. 터미널이나 cmd 들어가기
    3. repository 복사하기
        git clone [복사한_레포지토리_URL]
    
- 브랜치 정하기
    1. 브런치 파기([my-topic]에 본인 브런치이름, 나는 python했음)
        git checkout -b feature/[my-topic]
    2. 브랜치 이동
        git checkout [my-topic]
    
- 변경사항 추가 및 커밋
    1. 파일 이동
        cd cglab
    2. 파일 상태 확인  
        git status
    3. 파일 스테이징
        git add .
    4. 커밋 작성
        git commit -m "git사용법 정리"
    5. 깃허브로 푸시 
        git push origin feature/[my-topic]
    -> 2~5번 순서대로 하면 내 컴퓨터에서 수정한 사항들이 git으로 올라감

- Pull Request 만들기
    1. Github 들어가서 Pull Request 클릭
    2. New pull Request 선택
    3. base: main ← compare: feature/[my-topic] 선택
    3. 변경사항 설명 후 Create pull request 클릭
    4. 팀원들이 코드 보고 Merge 클릭

- git의 최신코드 불러오는 법
    1. main 브런치로 이동
        git checkout main
    2. 내 브런치로 이동
        git checkout [my-topic]
    3. 최신 코드 가져오기
        git pull origin main
    -> main branch 이동 후 최신코드 가져오면 됨
